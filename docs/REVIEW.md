- 캐시된 데이터의 예매 상태: `st.cache_data`가 매번 복사본을 돌려주고 `process()`가 검색 시점 기준으로 다시 계산함

- 외부 텍스트 출력: 마크다운 이스케이프 적용, HTML 출력은 고정 문자열만
- 브라우저 콘솔 오류 0건, 서버 로그 경고 0건 (Streamlit 1.67)
- 서울시 `sample` 실데이터 5건 전체 흐름 정상 (수집 0.11초)
